# PPhandcontrol — ready-to-run Windows folder

Created by **Mohamed Sherif**. Windows 10/11 x64.

> [!IMPORTANT]
> **Keep this entire folder together, including `_internal`.** Read **How to use.txt**, then start **PPhandcontrol.exe**. The app is free and unsigned, so Windows may show a first-run security warning.

This is the extracted application, with all its required runtime files.

- **PPhandcontrol.exe** — double-click to start the Windows app.
- [How to use.txt](How%20to%20use.txt) — setup, gestures, and P/Q controls.
- [License.txt](License.txt) — free use; no sale or false authorship.
- **_internal/** — required runtime; keep it beside the EXE.
- **licenses/** and the credits/notices — retain these when sharing.
- [tutorial/](tutorial/) — illustrated offline guide and validation notes.

To get the complete folder, [download the repository ZIP](https://github.com/mohamedsh283/PPhandcontrol/archive/refs/heads/main.zip), extract it, and open **PPhandcontrol-main → Download → PPhandcontrol**. No Python installation is needed. Download the whole folder; the EXE alone is insufficient.

For a smaller download containing only the app, use the [GitHub Release](https://github.com/mohamedsh283/PPhandcontrol/releases/latest).
